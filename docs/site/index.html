视频标注使用指南

打开标注工作台。通常只需在“标注”页完成工作；导出数据、填写基础资料和查快捷键分别放在“数据集”“设置”“帮助”。

1. 选项目和视频

新建或选择项目，再添加已经登记的视频。视频列表用于切换当前比赛。

首次标注一段视频时，先到“设置”填写人物与队伍。姓名不确定时可以用“A/B”或“近端/远端”，并保留身份未确认；人物信息由你填写。目前页面没有人物改名入口。

2. 标一个完整回合

  1. 找到回合开始，添加回合；结束时标记死球。
  2. 在触球时刻放一个“触球”标记，并选击球者。
  3. 在标签栏选择人物和角色，搜索或按维度找技术标签。
  4. 将标签拖到时间线新建区间，或拖到已有区间增加标签。
  5. 拖区间两端改开始/结束，拖块中间整体移动。动作很短时先放大或切到当前回合。
  6. 点选记录，在右侧补充判断并保存。

触球是一个时刻，动作和步法通常是一段过程。回合结束以死球为准，不把最后一次触球直接当成结束。

3. 圈出关注区域

先选一条记录，暂停在需要的画面，再展开时间线下方的“画面圈选”：

操作方法
矩形选择矩形工具，按住鼠标拖画
多边形逐点点击，Enter结束，Esc取消
移动/修改选中区域，拖区域或顶点
删除选中后点删除区域

圈选只记录当前画面，暂不自动跟踪。视频黑边不能圈选。完成后记得保存。

4. 保存与确认

“保存”保留本次修改；复核后在右侧“审核”中选择“人工确认”，再保存。改动后需要重新检查。看不清的技术点可保留未知，不必强选答案。

同一段视频可叠加手法、步法、球路等多个维度，并分别关联本人、对手或搭档。同一人物的相同标签重复拖入不会重复添加。

出现保存冲突时，你的草稿仍在。先比较内容，再选择是否重载，不要直接覆盖另一份更新。

5. 导出数据集

进入“数据集”，先保存标注，再生成一个导出版本。它固定当时的内容，之后继续编辑不会改变旧版本。

用途选择
保留草稿、交给他人复核完整标注JSON / JSONL
用于正式训练完成要求的审核、标签定义和比赛分组后导出训练数据

页面会列出缺少的条件。当前标签目录仍需专家核对，能标注和导出草稿不代表已经满足正式训练要求。

视频按原文件引用，不随每次导出重复复制。迁移到另一台电脑时，还要带上需要的视频，见迁移指南。

6. 常用快捷键

按键操作
空格播放/暂停
左右方向键前后移动
R / C回合起点 / 触球
A / F / T动作 / 步法 / 战术区间
I / O用当前时刻设置区间开始 / 结束
Ctrl或⌘ + S保存
Esc取消正在绘制或拖动的操作

在文字输入框内正常打字，不会触发播放器快捷键。需要精确时刻时，可在记录属性中填写时间；浏览器跳转位置仍需看画面复核。
