换设备部署与继续开发

本指南区分四件事：源码、运行环境、项目数据库、视频/权重。只复制源码，不能恢复后三者；也不要直接复制旧电脑的虚拟环境。

1. 选要带走的内容

目的带什么
继续整体Codex开发完整源码包或Git历史包、目标模块说明、当前验收记录
只改标注页面workbench源码包、它附带的共享依赖和文档；按需要带项目备份和视频
只开发模型models源码包、匹配的Asset清单/快照、需要的原片和权重；重建CPU或GPU环境
只剪辑导出render源码包、Timeline、允许制作的原片、FFmpeg和字体

源码包包含来源提交与文件hash。source-manifest.json核对包内容，CONTINUE_DEVELOPMENT.md指明模块边界、入口和测试。Git历史包保留提交信息；在目标设备用git clone <历史包> badmintonTV恢复仓库，再创建codex/<工作名>分支。

2. 先装轻环境，再按需装模型

完整部署入口为python scripts/deploy/manage.py，先运行profiles查看设备配置，再用plan检查将安装什么；具体参数以--help和部署说明为准。Windows与Linux/WSL的薄包装脚本只调用同一个部署入口。

选择本机的数据根目录和独立环境目录。当前电脑继续使用D:/video，其他设备不要求也有D盘。数据根中的data、platform、models、render、runtime分工不变；所有缓存/临时产物也计入容量。

播放/标注选workbench；资料处理选library；编码选render。模型数据准备使用独立cpu-prep；GPU基础和VL等按模型说明单独安装。CPU工作台不安装Torch/CUDA。软件包安装需要网络或另备相应平台的wheelhouse；源码包本身不是离线依赖安装盘。

在目标设备执行doctor，解决缺Python依赖、FFmpeg、字体、GPU或权重等具体缺项后再启动。GPU驱动由设备管理员维护，项目脚本不修改驱动或全局Python。

3. 迁移项目与媒体

  1. 暂停需要迁移的编辑和任务，生成一致性数据库备份。优先使用export-state的SQLite备份；不要把运行中的sqlite/WAL文件直接放进同步盘。
  2. 查看导出清单，确认源码提交、数据根、数据库备份及媒体引用。只带需要的原片；使用相同相对路径，重新核验大小与hash。
  3. 把备份放到目标设备的本地存储，不覆盖已有项目数据库。首次迁移先用新的数据库路径启动验证，确认后才决定后续主库。
  4. 权重按模型清单另行同步并验证hash/许可；不从旧venv复制框架。保留原设备数据作为回退。
  5. 打开工作台，在“设置→视频校验”对已复制的视频点“重新校验”。复制会改变文件身份，旧设备的校验结果不能直接复用；校验完成后检查项目、人物、播放、标注和快照，再进行正式编辑。

训练资料还须按原相对路径带上data/training/handoff/annotation-catalog.v1.json、training-registry.v1.json、目录引用的annotation-catalog/*.details.json，以及选中原片的PTS索引。它们都是小型清单/索引；只复制MP4或单独一个Asset清单还不足以恢复可信登记。export-state原样保留所指定的清单，其余引用文件按清单另行同步。

快照适合把一版数据交给训练设备；它不是完整项目数据库的替代品。旧快照不能因新设备读取而改变内容hash。训练数据的用途限制、人审状态与来源信息随迁移保留。

4. 在新设备交给Codex

建议给新对话以下任务：

阅读AGENTS.md、MODULES_AND_DEVICES、迁移指南以及该模块的CONTINUE_DEVELOPMENT和状态文档。先检查设备profile、输入文件与依赖，不下载大模型或重装所有环境。仅在自己的Git分支完成指定模块，用既定输入生成约定输出；为新阶段先写目标和验收断言，记录PASS/FAIL/BLOCKED/NOT_RUN。不要覆盖别的模块或同步运行中的数据库。

接着说明“本次只做哪个模块、用哪份真实输入、期望哪个输出”。用一个小输入先验收，再增加数据量。更新状态文档和提交SHA后，把提交或Git bundle回交主仓库，由主任务集成并跑跨模块验证。

5. 当前迁移能力的边界

已有源码分发、环境部署入口和文件协议不等于完成所有设备实机测试。新系统、GPU架构、浏览器和编码器要单独验收；没有访问目标设备时会标NOT_RUN。当前Windows→WSL自动执行桥仍固定D:/video；其他盘上的模型先按独立CLI和文件交接使用，接回网页队列要另行改造、测试该桥。当前不提供自动双向数据库合并、云同步、远程GPU队列或未实现细技法模型的训练成绩。
