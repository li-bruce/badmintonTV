页面整理与设备迁移：实施与验收

日期：2026-10-19。开始版本：main 321a30d。本轮先冻结断言，之后用实际结果更新；不沿用10月3日的PASS。本轮不训练模型、不新增下载视频或权重。

要交付什么

  1. 让用户主要看到视频、标签、时间段、人物、保存与导出。工程术语、实现说明和长篇审计解释移到帮助/高级信息；出错和未保存仍明确可见。
  2. 按可开发、可验证的边界列模块输入、输出、依赖及实际命令。共享接口、资料、工作台、模型、渲染分别打包；检索目前属于工作台，不声称已经成为独立服务。
  3. 普通电脑的播放/标注、CPU编码、CPU数据准备与GPU模型环境分别部署，迁移时重建环境，不复制虚拟环境。
  4. 提供源码包、Git历史包、部署/检查脚本、迁移步骤与给下一台设备上的Codex的交接说明。视频、权重、数据库另行处理，迁移不放宽用途或人审约束。

分工与结构

工作负责范围合并与依赖
平台子任务apps/platform界面及相关测试、平台文档从main建立自己的分支；不改变标注合同
部署子任务deployment、scripts/deploy、tests/deployment、根启动/打包配置共享源码清单、CPU部署与迁移；模型环境委托模型脚本
模型子任务scripts/models、environments/models*、相关测试/文档独立CPU准备/GPU环境入口，不执行本轮训练
主任务本轮计划、模块总说明、用户手册、分支集成、真实页面与解包验证不覆盖其他分支的未知改动，不推送远程

业务仍为一个项目。交接使用Asset/TrainingSnapshot/JobRequest/JobResult/Timeline等现有合同，原片用asset_id、相对路径和hash引用。不同设备各有自己的storage root；数据库只在其所在设备的本地文件系统打开。迁移SQLite要通过一致性备份或停服务后复制，不能同步运行中的WAL。

固定验收断言

ID目标及给定输入 → 执行必须达到的结果初始状态
P-01当前真实训练页 → 新布局浏览与选择视频常用视频/标签/时间线/保存清晰可达；长协议/来源说明不占主要界面；基础资料仍可填NOT_RUN
P-02真实原片与工程agent标注 → 拖标签/改区间/圈选/保存重载交互保留、时间/角色/区域保真，错误与未保存可见，不升级为人审真值NOT_RUN
P-03模块定义与现有入口 → 核对输入/输出/依赖和串联步骤每模块有可执行入口和产物；未实现的独立服务/训练器明确标注；CPU/GPU要求区分NOT_RUN
P-04指定提交 → 构建模块源码包、完整包与Git历史包包含所需代码/配置/资源/说明，记录版本和hash；不含数据/环境/密钥；不覆盖已有输出NOT_RUN
P-05干净解包目录及CPU profile → 部署计划/环境检查/启动参数化路径、任意cwd可运行，轻环境不依赖Torch/CUDA，未安装工具明确报告NOT_RUN
P-06文件迁移计划与数据库副本 → 执行校验既有文件不被覆盖；相对路径与hash可核，数据库一致性处理清楚；禁止运行中WAL同步NOT_RUN
P-07CPU/GPU模型profile → 参数检查、WSL脚本校验、CPU准备烟测CPU独立可构建，GPU分环境且缺依赖真实报告；不修改全局/驱动，不自动训练/下载权重NOT_RUN
P-08合入main → 相关回归、真实网页、部署/打包指南核验主线已集成、结果有证据、环境和失败记录完整，用户可按说明迁移继续开发NOT_RUN

每项记录输入、命令/动作、预期、实测、PASS/FAIL/BLOCKED/NOT_RUN、证据、原因和下一步。全部必需断言PASS才称本轮工程达标；跨设备硬件实机验证、专家动作真值和模型准确率另列，不能用脚本dry-run代替。

2026-10-19迁移审查追加P-06断言（实现前登记）：复制媒体后文件身份变化，必须提供明确的重新校验入口；已有项目中的视频也可重新校验，且不丢失标注与冻结快照。只恢复数据库但无法恢复视频访问不算迁移可用。

资源与发布边界

继续遵守项目700十进制GB及owner配额；本轮源码分发和测试产物预估峰值不超过500MB，先测再写，输出放D:/video的platform所属目录。迁移审查后追加一次真实复制验证：只复制一段约232MB训练原片及其小型索引到隔离迁移目录，模拟文件身份变化，不改原片，不全量复制资料库，仍在已预留500MB内。CPU回归复用现有轻量环境；干净部署验收另在runtime/platform下新建独立环境，由部署脚本最多预留2GB（含依赖缓存/临时文件），实际安装前再核算，不从平台500MB预算借用。不结束用户已有进程、不占GPU、不对公网开放或推送仓库。
