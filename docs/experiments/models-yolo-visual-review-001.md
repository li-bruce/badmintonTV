# YOLO11n-pose / ByteTrack：真实短窗 Agent 视觉检查 001

日期：2026-09-29。检查者：模型模块独立 Agent。**这是 Agent 对真实原片的视觉抽查，不是 human review、人工关键点真值或 precision/recall 评测。** 本次只读已有模型结果，以 Windows CPU 解码、绘制并逐张查看 9 张叠图；没有运行推理、使用 GPU、安装依赖或写入 `D:/video`。

## 结论

YOLO 结果保留了可见的场上人体、场外人员、未关联检测和缺失轨迹，没有把所有检测自动认作两名场上人物。但这段结果**仍不适合直接当作完整、已确认的 BST 人体/脚步输入**：抽查的 30–32 帧远端人物可见而未检测；65 帧弓步的双腿关键点聚向同一侧腿；66 帧同一个近端人物出现两套重叠检测。较高模型分数没有消除这些问题。

抽查中，绿色匿名 ID 1 对应近端红衣人物，青色匿名 ID 2 对应远端浅色衣人物；没有看到两者互换。这里只描述这些画面中的位置/服装关联，不命名身份，不宣称遮挡后稳定跟踪。紫色 ID 13 对应左侧高椅上的场外人员，不能把它算作场上选手。

## 仅由输出结构得到的统计

以下是这份模型输出的计数，不是正确率，也没有把未抽查帧视为已视觉确认：T1 出现在 90/90 帧；T2 出现在 79/90 帧，缺失帧为 `28..35`、`99..101`；T13 从 35 帧至 110 帧持续输出。报告的“0 帧没有任何检测”包含场外检测，不能据此推断每帧均检测到两名场上人物。`frames_with_missing_previously_seen_tracks=11` 与 T2 输出缺口一致。

已有推理报告记录：模型冷加载约 32.210 s，源解码和转换约 0.170 s，pose 分项约 1.738 s，ByteTrack 分项约 0.061 s；峰值 allocated `151,847,424` B、reserved `176,160,768` B。这里仅引用已有 GPU job 的结果，本次检查没有复跑。上述分项并非完整端到端时延；原报告 `steady_state_rtf=null`，不据此宣称实时通过。
