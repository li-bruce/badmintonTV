# 03：训练标注准备的本轮断言

日期2026-10-02，基线main `3dab169`，分支 `codex/models-annotation-readiness`。本文件在新实现前登记模块断言；主任务维护根阶段表，不能以模块检查替代A-04/A-05的浏览器保存导出或CTX专家/模型质量验收。

## 接口和数据流

`configs/models/taxonomy.v1.json` 提供版本化中文层级目录 → 01训练工作台保存标签、可见性、参与者和审核修订 → 01公共训练快照合同/fixture → models只读验证与归一 → 覆盖/真值来源/引用/组划分审计 → 严格训练视图和排除原因 → 有界原片PTS窗口准备。

taxonomy定义保持草案，支持状态与标签的人工审核分开；没有专家审定不宣称拟开放标签达标。粗标签不扩成细手法，匿名track不映射姓名；unknown、未标、看不清、不适用不形成负例。snapshot交换格式由01负责；模块内部归一结构只供函数使用，不作为另一公开格式。

预备使用现有WSL CPU环境与已下载原片/PTS，不新增模型下载、不启动GPU或正式训练。窗口产物优先只存源引用、PTS与检查结果，保留原片只读；拟新增峰值先限100MB，低于本轮2GB目标，执行前按models180GB/runtime分区和磁盘余量预检。任何帧候选都注明来源与审核状态，不混入human训练视图。
