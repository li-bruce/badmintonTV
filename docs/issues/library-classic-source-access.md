## 2026-10-05追加：至少11场1080p的访问阻塞

用户提高数量与画质要求后，旧三场低清不计新目标。本轮正常无认证B站请求1080仍返回360/720，当前Edge页面提示登录免费享高清视频；已保留里约半决赛页，请用户本人完成正常登录，未从浏览器凭据库读取或导出Cookie。登录只解除访问前提，仍须核实实际1080p、整场、允许下载及数量，不能预先承诺合格11场。

新浪2012标题1080实际仅852×480；央视2011全英公开HLS仅480×360；IA相关比赛均不到1080；论坛1080i候选的实际下载与逐行规格未知。详见 `docs/library/CLASSIC_MATCH_HD_ACQUISITION.md` 的本轮来源表。当前新增合格高清视频0，未占用新媒体预算。
