# 触球窗口的真实语义与精度边界

日期：2026-10-02。关联 A-07 / A-08，工程已验证；专家动作真值仍 BLOCKED。

本轮真实训练视频的原SHA及PTS已经核验，但用于范围算法的1000/2000/3000/6000ms marks、回合和阶段是明确agent技术fixture，未观察并确认相应帧实际发生发球、触球、死球或指定脚步。不得导入默认human truth视图，不能据此报告模型准确率。01公共快照仍给出未确认/词表临时/分组未分配等原有阻塞。

追加消费了root从真实网页导出的6条记录快照（content_sha d2deb512…），7个窗口及实际PTS核验通过；记录仍为agent/pending，unknown/unobservable和训练资格0保持。真实UI产物可消费不等于动作语义经过专家审核，本模块未重做网页/重启操作。

公共标注点为严格整数毫秒，真实PTS可能落在小数毫秒上。当前派生器保留原毫秒边界、PTS与差值；如果取整导致锚点帧落在半开范围外，返回candidate并说明，不静默修改mark。精确帧边界需求应通过后续公共合同的明确PTS端点方案扩展，不能在04私造另一种公共时间格式。

当前adapter不猜发球标签和步法阶段映射，必须使用显式ID+revision绑定。已知未归属触球落在范围内会降为candidate；缺回合/终点/阶段继续明确缺失或保守窗口。未知不是阴性、粗球种不变成细手法。

解除语义阻塞需由用户/教练确认真实原片中的人物、回合、触球及阶段，保留审阅来源、版本和时间证据；补完标注后重新派生，旧窗口ID/hash失效。此问题不阻塞本轮逻辑工具和训练用途隔离的工程交付，也不替代主任务的浏览器/专家验收。
