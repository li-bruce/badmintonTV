## 当前限制与下一阶段

- 展搓/收搓、后退小跳启动缺少专家可观测性定义、人工核实的正负例和按整场隔离的正式测试集，分类模型保留 unavailable；原因独立记录在 [细标签真值缺口](issues/models-fine-label-ground-truth.md)。
- 制作资料库仍为五段独立下载小样及一条回归派生素材；四段FBBench原场/球员映射未知，大学社团双打不能当世界前十比赛。本轮新职业包位于独立training目录，README称processed clips，其完整下载不等于十场未经剪辑转播，不加入制作资料库。
- 模型特征均保留events=[]；新增YOLO11n-pose+ByteTrack可输出镜头内匿名track，但真实小窗仍见漏检、重复人物和脚踝错位，不能宣称稳定身份、击球或细手法分类达标。
- 本地 Qwen 0.6B 在当前 24 条开发查询中，严格 JSON 基线 0/24、三示例提示 2/24；格式、schema 和语义均有问题。只限该模型/提示实验，记录见 [解析诊断](experiments/models-003-query-diagnostics.md)。工作台默认规则解析；外部 LLM 可配置，但未提供真实端点与密钥做联调。
- 公开视频、权重和标注各自记录许可；目前样片用于本地研究。人类需在真实区间和当前修订上确认，系统不会把 agent 审核提升为人类真值。

后续以新训练包做真实前处理与复用模型实验，先核实标签/时间轴和独立场次，再补细动作定义与正负例；双打关联与后退启动步按同样条件逐步加入。

## 环境与容量

控制面为 Windows 隔离 Python 环境与原生 SQLite；模型使用 WSL Ubuntu Conda，通过 JSON 进程边界通信，不跨系统共享 SQLite WAL。渲染使用独立 CPU FFmpeg。GPU 由账本、有限会话窗口和运行租约管理；无授权窗口或资源繁忙时明确 blocked，不争用显存。
