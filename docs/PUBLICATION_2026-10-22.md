## 隐私处理与复现边界

全历史初检为245个提交、18个项目分支、1069个唯一文本blob，无二进制blob。正则命中已人工复核：私钥头、literal-secret、user:pass URL 来自安全测试；10.3.9.x 是 NVIDIA curand 版本号，不是内网地址。

公开历史将个人 Windows 主目录换成 USER 占位，私人 Git 邮箱换成账户 noreply 地址，移除共享对话访问链接及私有会话标识。通用 D:/video 容量布局、公开模型/数据来源、许可证、版本、测试输入和失败记录保留；这些不是本机凭据。系统运行路径与 PID 只是历史证据，不能用作当前设备状态。原始 Git 与本机配置留在原设备，不上传 Git bundle 或源码 ZIP 绕过审查。

原始提交编号仍可能出现在旧文档内，公开版对照表为 `docs/history/published-commit-map.json`。新开发从公开仓库克隆，不把原始未脱敏历史重新合并或推入远程。
