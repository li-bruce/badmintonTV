# 标注页面简化设计（2026-10-19）

目标：用户进入页面后依次选项目、选视频、标注、保存、导出数据集。常用操作常驻；实现细节收进设置、帮助或数据详情。保留所有数据校验和审核限制。

## 页面结构

- 左栏：项目、视频、标签。人物/队伍、操作人信息归入项目设置，仍由人填写。
- 中栏：播放器、播放与逐步定位、触球/区间快捷操作、圈选工具、紧凑时间线、记录列表。
- 右栏：当前标注的时间、人物、标签判定、审核；态势、证据、审核来源按需展开。保存固定在页头，未保存和冲突必须可见。
- 顶部入口：标注、数据集、设置、帮助。数据集导出、比赛划分从主标注画面移到独立视图。
- 制作页面：统一为“工作台 / 素材 / 检索 / 剪辑 / 任务 / 设置”，去掉装饰编号和开发宣言。技术JSON和诊断入口可展开。
